## 2024-06-28 - [Performance: React Native SVG Rendering]
**Learning:** In a React Native context (particularly Expo), statically rendered complex SVGs with multiple nodes, strokes, gradients, and defs (like a dynamic but invariant game board graphic) present severe performance bottlenecks. Rendering these inline inside a component whose state changes frequently (e.g., animations, moving pieces) causes massive, continuous re-evaluations and subsequent frame drops because the heavy SVG hierarchy needs to be reconciled on every tick.
**Action:** Extract any complex, static (or infrequently changing) SVG backgrounds into their own independent React components. Wrap these extracted components with `React.memo` (and explicitly set their `.displayName` for code style rules compliance). This isolates the rendering boundary, letting the SVG engine skip reconciliation as long as its core props (like sizing or theme constants) remain unchanged.
