## 2024-08-07 - React Native SVG Render Bottlenecks\n**Learning:** The `react-native-svg` elements cause significant render latency on the JS thread during frequent `gameState` updates (e.g., piece movements) because they force deep diffing of the tree. Re-renders of complex visual components like the board background and animated components like `TamarindSeed` needed to be optimized using standard React memoization techniques to prevent frame drops.\n**Action:** Use `React.useMemo` for heavy, static SVG layers and `React.memo` (typed as `React.NamedExoticComponent`) for frequently rendered interactive SVG pieces whose base props do not change during an animation.
