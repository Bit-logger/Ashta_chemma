## 2024-05-24 - SVG Re-rendering Optimization in Board.tsx\n**Learning:** In React Native with `react-native-svg`, drawing lots of small static SVG components (like a game board grid) directly in a component that frequently receives state updates (like game loop/animations) is a bottleneck.\n**Action:** Use `React.useMemo` to extract static SVG background layers in game boards so they do not needlessly redraw every frame when game state (e.g. piece positions) updates.
