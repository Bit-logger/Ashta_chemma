## 2024-03-24 - React Native Animation Performance Loop Bottleneck
**Learning:** In a step-by-step game loop (like `GameScreen` animating a piece moving square by square), updating the state every ~200ms causes the entire screen and *all* child components to re-render. If heavy SVG elements like the board background, dice, and stationary player pieces aren't memoized, the JS thread spends significantly more time computing diffs for identical static props, which can cause frame drops and choppy animations.
**Action:** Extract heavy, static SVG components (like grid lines) into separate components, and proactively wrap them (along with repeating stationary items like dice trays and player pieces) in `React.memo` whenever their props are mostly primitive or stable. This eliminates wasted re-renders across rapid sequential state updates.
