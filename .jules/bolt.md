## 2026-06-26 - [Board SVG Extraction]
**Learning:** In React Native applications with complex SVGs used as backgrounds (e.g., game boards), these SVG components can cause severe performance issues (like frame drops during animations) if they re-render when they don't need to. Extracting these static complex SVGs into separate components and wrapping them with `React.memo` is a highly effective optimization technique.
**Action:** Always extract static SVG elements into separate memoized components when they are part of a view that frequently updates (e.g., game board during piece movement), preventing unnecessary rendering cycles and keeping the UI smooth. Ensure that only primitive values or strictly memoized objects are passed as props to the memoized background component.
